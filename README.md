# สวนดาว (Planet)

เกมสำรวจและปรับแต่งดาวเคราะห์ 7 ดวง เล่นได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์

**เล่นได้ที่:** https://icelolan-ai.github.io/Planet/

## เล่นอะไรได้บ้าง
- เปิดเกมแล้วจะเจอหน้าเริ่มต้น: ดาวเคราะห์ที่คุณปรับแต่งหมุนรอบดาวฤกษ์ แสดงความคืบหน้า และเคล็ดลับเปลี่ยนไปเรื่อย ๆ กดปุ่มเริ่ม (หรือ Enter) แล้วจะเล่นวิดีโอเปิดเรื่องสั้น ๆ แบบไม่มีเสียง (ข้ามได้) ก่อนเข้าสู่แผนที่อวกาศ เปิด/ปิดเสียงและเปลี่ยนภาษาได้ตั้งแต่หน้านี้
- ธีมอวกาศสีม่วงสดแบบการ์ตูน: การ์ดกระจก ปุ่มไล่สี และดาวเคราะห์ที่แรเงาแบบการ์ตูน มีขอบเรืองแสงและหลุมอุกกาบาต
- พื้นหลังเป็นแผนที่ดาว มีทางช้างเผือก เส้นกริด และวงโคจรสีทองพร้อมจุดเล็ก ๆ ที่เคลื่อนไปตามวง ดาวแต่ละดวงลากหางแสงสีของตัวเองไปตามวงโคจร มีลูกบอลเงาวาวสีสดลอยอยู่ และมีเกรนละเอียดคล้ายงานพิมพ์ทับทั้งภาพ
- ในมุมมอง 3D วงโคจรเป็นท่อเงาสีชมพู มีหินขรุขระในแถบดาวเคราะห์น้อยและแถบไคเปอร์ และลูกบอลสีสดคล้ายของเล่นลอยอยู่รอบระบบ
- เปิดครั้งแรกจะมีหน้าแนะนำ 3 หน้า (ปัดหรือกดถัดไป) และเปิดดูอีกครั้งได้จากเมนู
- เริ่มต้นที่สถานีอวกาศข้างดาวฤกษ์ (ออกแบบตามสถานีอวกาศนานาชาติ ISS: โครงถัก แผงโซลาร์ปีกยาว แผงระบายความร้อน ถังเชื้อเพลิงหุ้มฟอยล์ทอง เครื่องยนต์ไอออน แขนกล และยานที่มาเทียบท่า) แตะเพื่อเข้าไปสำรวจเป็นภาพ 3 มิติและออกแบบสถานีจากโมดูล 11 แบบ ค่าทางวิศวกรรม (พลังงาน ความร้อน ลูกเรือ มวล) มีผลต่อความเร็วและเวลาเดินทางของยาน
- บินไปตามเส้นทางบนแผนที่ ดูระยะทาง (กม.) และเวลาเดินทางระหว่างดาว
- ปรับแต่งดาวด้วยแถบเลื่อนที่เปลี่ยนตามสภาพแวดล้อมของดาว เช่น ความร้อน ลาวา น้ำ พืช น้ำแข็ง พายุ วงแหวน อายุดาว และขนาด
- สร้างระบบนิเวศ แล้วดูสัตว์ ผู้ตั้งถิ่นฐาน สภาพอากาศ ออกซิเจน และสัดส่วนน้ำและดิน
- ดูแลเศรษฐกิจของดาวให้โตโดยไม่ทำลายธรรมชาติ
- แตะดาวเพื่อส่งคลื่นกระเพื่อมไปทั่วพื้นผิว ถ้าปล่อยดาวไว้เฉย ๆ สักพัก เมฆ พืช และพายุจะค่อย ๆ เปลี่ยนไปเอง (เป็นแค่ภาพ ไม่กระทบตัวเลข)
- เลื่อนแผนที่ออกห่างจากดาวฤกษ์ ท้องฟ้าจะเปลี่ยนจากโทนอุ่นเป็นโทนเย็น พร้อมบอกว่าอยู่ในเขตไหนของระบบ (เขตอาศัยได้, แนวหิมะ ฯลฯ) และได้แสงมากแค่ไหนเมื่อเทียบกับโลก
- แท็บ "ข้อมูล" มีภาพตัดชั้นภายในดาว ซึ่งเปลี่ยนตามค่าที่ปรับ
- ลงสำรวจแล้วมองจากมุมสูงแบบเกมวางแผน (RTS): ลากเพื่อเลื่อนดู บีบนิ้วหรือหมุนล้อเมาส์เพื่อซูม หมุนสองนิ้ว (หรือคลิกขวาลาก, Q/E) เพื่อหมุนมุมมอง ใช้ WASD/ลูกศรบนคีย์บอร์ดได้ แตะโฮโลแกรมเพื่อบินเข้าไปดูข้อมูล
- พื้นผิวแบบสมจริง (ค่าเริ่มต้น): พื้นดินลงสีตามดาว (หญ้า ดิน ทราย หิน หิมะ ดินแดงทะเลทราย) มีถนนดิน เมืองแบบชายแดน (บ้านไม้ ร้านค้าหน้าป้าย โบสถ์มีหอระฆัง โรงนา เต็นท์ ลังไม้ ถัง กระสอบ รั้ว เกวียนมีผ้าคลุม ควันจากปล่องไฟ และผู้คนเดินไปมา) เมื่อมีระบบนิเวศจะมีหมู่บ้านเล็ก ๆ อีก 2–3 แห่งเชื่อมกันด้วยทางเกวียน ถ้ายังไม่สร้างระบบนิเวศจะเป็นแคมป์นักสำรวจ แผนที่แต่ละดาวกว้างราว 4.6 เท่าของเดิม และซูมออกดูทั้งแผนที่ได้ พร้อมต้นไม้ พุ่มไม้ หญ้า หิน ตามชนิดดาว และแสงแดดมีเงา
- กดปุ่ม 🌄/🧊 เพื่อสลับเป็นแบบไดโอรามา: เกาะลอยแผ่นสี่เหลี่ยมขั้นบันได ต้นไม้ทรงกล่อง ก้อนน้ำแข็งกับเพนกวิน ต้นไม้เจียระไนสีพาสเทล
- กด 🛬 ลงสำรวจ ในหน้าดาว เพื่อลงไปบนพื้นผิวที่สร้างจากค่าที่ปรับไว้จริง (ภูมิประเทศ ทะเลหรือลาวา พืช สภาพอากาศ นิคม) มีจุดสำรวจแบบโฮโลแกรม ทัวร์อัตโนมัติ และดาวก๊าซจะเป็นการบินผ่านทะเลเมฆ
- บนแผนที่ ดาวทุกดวงหมุนตามความยาววันของตัวเอง มีวงโคจรรอบดาวฤกษ์ เขตอาศัยได้ แนวหิมะ แถบดาวเคราะห์น้อย แถบไคเปอร์ ดวงจันทร์ ดาวหาง และดาวตก ปรับความเร็ว (หยุด, 0.5×–4×) ได้ที่ปุ่มมุมขวาล่าง
- ปุ่ม 3D สลับเป็นมุมมองระบบดาว 3 มิติ ดาวทุกดวงโคจรรอบดาวฤกษ์ มีดวงจันทร์ แถบดาวเคราะห์น้อย และกลุ่มดาวเล็ก ๆ ลากเพื่อหมุน บีบนิ้วหรือเลื่อนเพื่อซูม แตะดาวเพื่อบินไป
- ในหน้าดาว แตะดาวหรือพื้นหลังเพื่อพับแผงปรับแต่งเป็นปุ่มเล็ก ๆ แล้วกดปุ่มเพื่อเปิดกลับ
- ปรับโทนพื้นหลังได้ที่ปุ่ม 🌘 ข้างวงความคืบหน้า (ม่วงสด, น้ำเงินเข้ม, มืดสนิท)
- ผงละอองเล็ก ๆ จุดสี ประกายดาว และดาวห้าแฉกลอยและกะพริบอยู่ในพื้นหลัง ทั้งในแผนที่และมุมมอง 3D ปรับปริมาณอนุภาคและเอฟเฟกต์ได้ที่ปุ่ม ✨ (น้อย / ปกติ / มาก)
- ซูมเข้าไปใกล้ผิวดาวได้มาก รายละเอียดพื้นผิว คลื่นน้ำ เมฆ และแถบก๊าซจะละเอียดขึ้นเมื่อซูม
- ความเร็วยานเริ่มต้นเป็น "ช้า" ปรับได้ที่ปุ่ม 🚀
- เปลี่ยนภาษาไทย / อังกฤษได้ที่ปุ่ม TH/EN มุมขวาบน
- มีความลับซ่อนอยู่ในระบบดาวนี้ ลองสร้างชีวิตให้ครบทุกดวง หรือแตะดาวฤกษ์ดูหลาย ๆ ครั้ง
- เปิดเสียงได้ในเมนู เสียงทั้งหมดสังเคราะห์ด้วย Web Audio จึงไม่ต้องมีไฟล์เสียง

## โครงสร้าง
แอปทั้งหมดอยู่ใน `index.html` ไฟล์เดียว (วิดีโอเปิดเรื่องแยกเป็น `intro.mp4` และ `intro.webm`) และฝัง three.js r128 (MIT) ไว้ในไฟล์ จึงไม่ต้องพึ่ง CDN
ถ้าต้องการเพิ่มแถบเลื่อน ชนิดดาว สัตว์ หรือทรัพยากร ให้แก้ข้อมูลใน `CONTROLS`, `BIOMES` และ `PLANETS` ตามคอมเมนต์ในไฟล์

ความคืบหน้าของผู้เล่นจะถูกบันทึกไว้ในเบราว์เซอร์ของแต่ละเครื่อง
