# สวนดาว (Planet)

เกมสำรวจและปรับแต่งดาวเคราะห์ 7 ดวง เล่นได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์

**เล่นได้ที่:** https://icelolan-ai.github.io/Planet/

## เล่นอะไรได้บ้าง
- บินไปตามเส้นทางบนแผนที่ ดูระยะทาง (กม.) และเวลาเดินทางระหว่างดาว
- ปรับแต่งดาวด้วยแถบเลื่อนที่เปลี่ยนตามสภาพแวดล้อมของดาว เช่น ความร้อน ลาวา น้ำ พืช น้ำแข็ง พายุ วงแหวน อายุดาว และขนาด
- สร้างระบบนิเวศ แล้วดูสัตว์ ผู้ตั้งถิ่นฐาน สภาพอากาศ ออกซิเจน และสัดส่วนน้ำและดิน
- ดูแลเศรษฐกิจของดาวให้โตโดยไม่ทำลายธรรมชาติ

## โครงสร้าง
แอปทั้งหมดอยู่ใน `index.html` ไฟล์เดียว และฝัง three.js r128 (MIT) ไว้ในไฟล์ จึงไม่ต้องพึ่ง CDN
ถ้าต้องการเพิ่มแถบเลื่อน ชนิดดาว สัตว์ หรือทรัพยากร ให้แก้ข้อมูลใน `CONTROLS`, `BIOMES` และ `PLANETS` ตามคอมเมนต์ในไฟล์

ความคืบหน้าของผู้เล่นจะถูกบันทึกไว้ในเบราว์เซอร์ของแต่ละเครื่อง
